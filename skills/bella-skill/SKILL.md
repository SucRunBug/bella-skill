# Bella Skill

把用户的实际任务交给合适的技能。分类是目录导航，不是必须逐层提问的菜单。

## 先承接任务

- 从对话恢复目标、本轮交付物、材料、已有产物和约束。已有大纲、草稿、音频、实验结果或粗剪时间线时，从当前阶段继续。
- 用户明确指定某个技能时优先使用它；只问会改变执行的缺口。普通问答或轻微编辑直接完成，无需强制路由。
- 只有输入 `$bella-skill` 或询问用法而没有任务时，简短介绍英语、科研、自媒体、3D 游戏四类，并请用户直接描述想做的事。

## 发现与选择

以 [技能目录](references/catalog.json) 为本合集候选真源。先运行下面的脚本，路径相对本 `SKILL.md` 的实际位置，不能假定当前工作目录就是安装目录：

```bash
python3 "<本技能目录>/scripts/list_skills.py"
```

它输出每项的名称、实际路径、当前版本描述、接手与交付边界，以及缺失或名称冲突。支持仓库分类目录和安装后的同级目录。只读取清单中的技能，不遍历无关个人文件。

| 分类 | 当前请求 | 优先候选 |
|---|---|---|
| 英语 | 日常聊天、复述、IELTS/PTE/TOEFL 口语训练 | `bella-speaking-coach` |
| 英语 | 英语音频逐句听原声、中英对照、跟读网页 | `bella-audio-listening` |
| 科研 | 文献、研究设计、实验、分析、论文、科研图表 | `bella-ai4s` |
| 自媒体 | 把观点或口播做成半调纸拼贴画面 | `bella-ai-collage-maker` |
| 自媒体 | 把已有音乐和歌词制作成可编辑的程序化二维动画 MV | `bella-music-mv` |
| 自媒体 | 给原始口播或粗剪添加字幕、抠像和包装 | `talking-head-video-packaging` |
| 自媒体 | 从主题、资料、大纲或草稿写文案 | `bella-writer` |
| 自媒体 | 读取或拆解指定视频，取得原话、线索和画面备注 | `yanmai-video-reading` |
| 3D 游戏 | 从描述、参考图或模型制作 3D 资产、绑定、动画与接入 | `tripo-3d` |

关键词只辅助定位。以用户要拿到的产物、实际材料和候选的接手边界决定；科研汇报用英语，不等于英语陪练；听力网页有 HTML，不等于自媒体写作；音乐与歌词驱动的动画 MV 选择 `bella-music-mv`，口播字幕包装和拼贴制作包各有自己的入口；3D 资产技能不承诺独立完成整个游戏。

## 在当前对话执行

1. 完整读取选中技能的 `SKILL.md`，执行到相关环节再读取其资源。先核对实际输入、工具、交付与停止条件；目录说明与正文不一致时以正文为准。
2. 简短说明“这次使用 `{技能名}` 完成 `{本轮交付}`”，同一轮开始执行。用户已要求执行且材料足够时，不追加“是否开始”。
3. 默认一次选一个技能。当前分工仍匹配就继续；目标已完成就结束。不要为了凑齐分类而依次调用整个合集。
4. 一个请求确实需要衔接多个技能时，从最终交付倒推依赖，只安排必要步骤。例如先读取指定参考视频再写稿；用户已有文字稿时跳过读取。前一步结束后，根据实际产物重新判断下一步。
5. 交接保留用户原始目标、素材路径、已确认事实、产物、待核实事项和明确约束。不要求用户重发指令，不把“读取技能并执行”说成创建了独立 Agent。

当前流程有进展就留在当前技能。只有目标、阶段或关键前提变化，或者发现具体能力缺口时，才回到主入口重新选择。用户只要推荐时给推荐，不擅自执行。

## 缺失能力与安装

脚本标记缺失或名称冲突时不能宣称已调用。可在宿主技能列表中定位同名技能，核对其 `SKILL.md`；仍不可用时说明具体缺项。需要安装时提供：

```bash
npx -y skills add SucRunBug/bella-skill -g --all
```

只安装主入口不会自动包含九个成员。目录脚本只发现资源，不下载、更新或安装；安装依用户要求执行。

## 边界

- 遵守当前项目与用户已有规则；本合集不依赖作者个人知识库或原电脑路径，也不替换项目流程。
- 沿用已有授权。路由不会扩大读写、外部沟通、发布、安装或付费权限；具体操作按用户请求和下游技能的实际条件判断。
- 使用当前已具备的媒体与证据，不能把工具缺失伪装成完成。拼贴默认交付静帧与视频制作包，生成 MP4 是另一项明确请求；口播包装需要可用的剪辑环境。
- 音乐 MV 请求以音乐、歌词和最终动画成片为目标，按下游新手引导补齐必要输入；不能把分镜文档、歌词滚动页或未渲染的工程报告成已完成视频。
- 下游技能交付范围外的需求回到这里判断，不把某一条示例固化为跨任务长链。不自动启动其他 Agent。
- 最终只报告真正完成的结果、必要限制和实际使用的技能。
