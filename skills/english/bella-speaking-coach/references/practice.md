# 练习方式

## 兴趣话题

选择用户已有内容可说的小话题，避免直接抽象到整个人生观。例：喜欢的一道菜、想去的地方、最近做成的一件事。一次一个问题，先听答案，再从答案中的细节追问。

用户已选择日常练习后，可以从 “What is one thing you enjoyed today?” 开始。首次“开始练”且未选择目标时，先完成日常／考试入口选择。回答困难就缩小为 “What did you have for breakfast?”；用户有兴趣或指定场景就立即改用他的内容。

别为了完成话题清单突然换题。话题结束由用户表示、任务已完成或时间预算决定。十分钟是安排任务量的默认值，未计时不要声称实际已练满十分钟。

## 生活描述

由容易到复杂选择一项，按实际表现调整，而非强制逐级闯关：

| 任务 | 必要时给的提示 |
| --- | --- |
| 描述正在做的事 | 正在做什么、接下来做什么 |
| 描述身边物品 | 外观、材质、用途、自己的感受 |
| 讲述今天的一件事 | 发生了什么、先后顺序、结果或感受 |
| 解释选择或比较 | 选择什么、为什么、与另一种有何差别 |

提示一次给一个，只有用户请求完整提纲时才全部给。练物品描述时，不替用户编造物品样子；未收到图片或描述就先请用户选一件东西。

## 材料复述

先读取实际材料。用户刚做完听读练习时可复用他提供的短文或要点，不必再让他寻找另一份材料。

先问用户能讲出什么。需要帮助时可给三至五个关键词或简短内容要点，标明已经提示；随后让用户组织语言。完整示范仅在用户要求或作答后提供。

反馈分开处理语言与内容。事实纠错必须能对应原材料；材料不完整时，只评估可见部分。复述可以有多种正确说法，不按 AI 示例逐字匹配。

## 调整难度与反馈量

- 只能说词组：接受词组，给一个短句框架，再邀请说自己的内容。
- 能说短句：增加一个细节或理由；优先修正一个影响意思的错误。
- 能连贯叙述：追问时间线、感受或因果，关注反复出现的语言问题。
- 已能自然交流：练澄清、比较、解释观点和回应追问，保留用户原本的表达风格。

难度依据当次回答调整，不以一次短答确定 CEFR 等级或考试分数。短练习可以只做一次回答、一个反馈和一个复练；不要增加积压的“作业”。

## 反馈形态

语音交流优先简短说出原句、一个改法和原因；文字或练后报告可以用表格。示例：

“你说的是 `Yesterday I go to the park.`。因为是昨天，可以改为 `Yesterday I went to the park.`。现在再讲一遍昨天做的事，试着自己用过去式。”

这是语法问题的教学示例，不是用户真实回答。自然度建议用“这句也能用；如果你想强调……，可以说……”。缺乏音频证据时，仅谈可见语言，避免推测说话速度、发音和情绪。
