# 从一句产品介绍开始

本文件用于首次沟通、补齐产品信息、解释风格与交付。执行细节在 [production-workflow.md](production-workflow.md)，风格与技术比较在 [styles.md](styles.md)。只有需要引导新手或澄清输入时才读本文件。

## 用户最少需要提供什么

先利用本轮与前文已有的信息、用户指定的文件和可访问官网，不让用户重复填写。用户可以只说三件事：

1. **产品是什么**：产品网址，或一句真实介绍；尚无官网也可提供功能事实。
2. **给谁看、最想表达什么**：目标用户和一个主卖点；不用先写完整广告文案。
3. **放在哪里或做多长**：如官网首屏、小红书竖屏、发布会横屏，或“20 秒左右”。

不要求用户先理解 GSAP、Remotion、帧率、编码、弹簧、BPM 或摄像机。技术由 agent 根据画面、运行环境和交付要求推荐。网址不是必填：产品事实足够时，直接用事实制作。

可给用户一个能直接照抄的例子：

> 我的产品是一个给自由职业者用的记账工具，网址是……。这次只想突出“拍收据后自动分类”，做一个约 20 秒的竖屏宣传片。风格你来选，需要可编辑源码。

这段是输入示例，不是可搬到其他产品上的事实。没有“自动分类”功能的产品不能沿用该卖点。

## 如何补信息而不变成问卷

- **已有足够事实**：整理 brief，写中文分镜并继续实施。把用到的可逆默认值说明清楚，不增加“先确认定位、再确认文案、再确认每一镜”的审批链。
- **有网址、没有完整卖点**：先看官方介绍、实际界面和用户指定资料，提炼一个能在画面中证明的价值。能合理确定受众时，说明判断并继续；不把网上宣传数字当已验证效果。
- **无网址但有功能事实**：用用户给的事实。Logo 缺失可先做产品名的可编辑文字标识；真实界面缺失可做明确标注的演示界面，或选择不依赖 UI 的叙事风格。
- **连产品或核心能力都未知**：只补问阻止动手的内容，例如“产品是做什么的、给谁用、希望观众记住哪一点？”已有答案的部分不再问。与此同时可检查文件、环境和用户给的参考。
- **指定了必须使用的素材，却没有提供且无法访问**：继续能做的脚本、布局和工程准备，准确指出缺哪一项。不能把缺失素材假装为已取得，也不能悄悄用另一个产品替代。

信息可被合理补全不等于可以补造产品事实。时长、比例、字体、背景和声音形式通常可以用说明过的默认值；功能、价格、客户证言、合作关系、收益数字和发布状态不能靠想象补全。

## 只展示最相关的三个风格

先按产品类型、卖点和现有素材，从 [styles.md](styles.md) 里挑 **3 个最相关**的方向。解释用户会看到什么，并给一个推荐；不要一次抛出九种风格和六套技术让新手决策。

| 用户情况 | 推荐时展示的三个方向 | 解释重点 |
|---|---|---|
| 音乐、内容、设计工具，有封面或作品 | `spotify-premium`、`minimal-ui`、`shape-morph` | 作品成为主角；简洁界面展示；一个形状串联操作 |
| SaaS、管理工具，有真实界面 | `real-ui`、`minimal-ui`、`social-launch` | 看清怎么用；连续演示；首秒卖点与快速证明 |
| 开发工具、API、AI 基础设施 | `tech-launch`、`real-ui`、`social-launch` | 数据流解释功能；真实操作作证明；短促发布节奏 |
| 摄影、设计、电商，有优质照片 | `apple-continuous`、`spotify-premium`、`footage-hybrid` | 照片与玻璃连续变化；作品卡片；真实镜头和 UI 混剪 |
| 自动化、Agent、代办服务 | `outcome-story`、`tech-launch`、`real-ui` | 交付任务到看到结果；机制；真实执行过程 |
| 实体产品，有照片、视频或模型 | `footage-hybrid`、`apple-continuous`、`social-launch` | 真实使用场景；细节与材质；卖点与证据 |

推荐措辞示例：

> 我建议做“真实 UI 拆解”：把你产品的收据、分类和报表拆成可运动的组件，让人看懂一次操作。另两种是“简洁连续形变”，画面更干净，以及“社交发布快切”，开头更直接。我先按真实 UI 方向做 20 秒竖屏，用现有产品资料写分镜并开始制作；你随时可以换方向。

这个展示是帮助理解选择，不是等待批准的固定关卡。如果用户明确说“先给我选风格”，就先停在选项；如果说“你来决定”“全自动”或已经选定方向，不再要求回答风格问卷。

用户喜欢某个案例时，沿用它的视觉规律，而不是照搬品牌。例如“像 Spotify 那支”可理解为：居中的深色舞台、一个主视觉贯穿、卡片与搜索连贯交接、受控透视、品牌色点睛、稳定的下方信息条。先把这些规律转成用户产品的内容。

## 技术怎么解释给用户

**风格是观感，技术是实现方式。** “苹果发布会感”不代表必须 Three.js，“有纵深”也不代表需要 Blender。默认只给一个简短技术建议，例如：

> 这次主要是界面、文字和卡片，我建议 HTML/SVG 加 GSAP：容易预览和修改，也能逐帧导出。无需让你配置三维软件。

需要时再解释这些差别：

- HTML/Canvas/SVG：适合简洁 UI、图形和可随时跳到任意时间的网页预览。
- GSAP：适合复杂的二维时间线、蒙版和组件衔接，便于集中调整节奏。
- Remotion：适合多镜头、字幕、多个比例和后续经常替换文案的组件工程。
- Three.js：适合真的需要相机、空间遮挡、3D 产品或旋转陈列的镜头。
- Blender：适合实体产品、真实材质灯光、结构拆解，需要更多模型与渲染准备。
- 混合：真实镜头、产品 UI、二维文字、三维镜头按需要组合，后续统一时间线与音轨。

使用已存在的环境和工具，缺库或缺渲染器时给出可行替代。不要宣称某个尚未安装的软件、模型、服务或命令已可用。

## 用户不必一次准备的可选材料

按所选风格补充需要的材料，不把下面整表变成必填项：

| 材料 | 什么时候有用 | 暂时没有怎么办 |
|---|---|---|
| Logo、品牌色、字体 | 所有品牌成片 | 从有权使用的官方资料提取；或用产品名文字标识与临时中性色，记录假设 |
| 真实截图、录屏、操作步骤 | `real-ui`、`minimal-ui` | 可访问时自行检查公开界面；否则按已确认功能制作演示画面并标清，不能冒充真实截屏 |
| 作品封面、商品图、照片 | `spotify-premium`、`apple-continuous` | 选择不依赖这些材料的风格，或在用户授权范围内制作原创辅助视觉 |
| 真实短视频 | `footage-hybrid` | 少量高质量片段即可重组；没有时换路线，不能把占位卡片说成真实影片 |
| 模型或多角度照片 | 需要真实三维产品特写 | 无模型可先选二维摄影路线；涉及额外付费建模或服务另行处理 |
| 音乐、旁白、发音要求 | 用户希望有声音 | 可无声或只做 UI 音效；不要默认每部宣传片都要 BGM 或配音 |
| 可信数据、评价、客户案例 | 要出现效果或证明 | 只用可核实事实；无数据就展示操作前后可观察的变化 |

无需密码或私密后台也能制作时，不要求访问。公开官网无法访问时，可用用户已给的事实与截图继续。

## 声音、时长与平台的默认决策

- 用户要无声、只要音效或指定旁白，直接尊重。没有声音偏好时，按内容推荐无声、UI 音效、音乐或旁白中的最少必要组合，并在 brief 中写明。
- 选了强调踩拍的风格，也可以用无音乐的时间节奏表完成；如果采用音乐，应按实际音轨分析，而不是机械假设 120 BPM。
- 平台明确时再定画幅、安全区和字体大小。横屏转竖屏要重新排版关键内容，不能只裁正中间。
- 只给了时长时，可按内容推荐一个主比例并说明假设。只给了平台时，根据卖点数量给一个合适的短片时长；让用户知道可修改，不强求一次报齐全部规格。
- 默认范围是本地创作和交付。平台名用于决定格式，不代表用户授权上传、投放广告、发布、购买音乐或开通付费服务。

## 让用户知道接下来会发生什么

制作请求可用简短说明保持可预期：

> 我会先整理产品事实和 5–7 镜中文分镜，再做关键画面与转场小样，检查文字、节奏和声音后导出成片，同时保留可编辑工程。过程中你可以直接说“第 6 秒改成展示报表”这类具体修改。

这段不是每次必须重复的口号。根据任务规模缩短过程：一个 6 秒 Logo 片不需要完整营销策划；复杂的 30 秒多素材影片才需要较细的资产与镜头组织。

遵守用户当前要的产物：

- **只要提示词**：输出能独立执行的定制提示词，明确事实、变量、素材、镜头、声音和交付；不擅自生成全片。
- **只要方案或脚本**：交 brief 与中文分镜，说明下一步需要什么，不将“直接实施”规则扩张到制作。
- **只要预览**：交用户约定的关键帧或小样，明确范围；不声称已有最终 MP4。
- **要成片／帮我做**：完成实现、实际渲染、验收和可编辑交付，不停在分镜或 HTML 文件。
- **要同风格复刻**：在授权范围内提取视觉规律，使用用户产品事实；原例品牌、歌曲、功能和数字不自动继承。

## 交付怎么让新手用得上

最终说明以可播放视频为先，再给工程和复现入口。写清实际时长、画幅、声音形式、交付位置，以及任何尚未完成的部分。若只成功交付预览，直接说明是预览。

提供自然语言定点修改方式，例如：

> 可以直接告诉我“0:04–0:07 把搜索换成拍照识别”“结尾品牌多停一秒”“保留画面但去掉音乐”。我会定位对应镜头修改，检查衔接并重新导出。

无需引导用户先学代码。工程交付用于后续替换产品信息、素材、颜色、文案、声音与时间，而不是把制作负担交回用户。
