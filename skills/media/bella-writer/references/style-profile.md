# 风格档案规则

优先使用用户在当前对话中明确给出的要求，以及用户指定的风格档案。未指定位置时，按需读取当前项目的 `output/writing/style-profile.md`；不存在则继续，不猜测个人偏好。

用户明确要求 Bella 文风时，可以读取 [作者公开风格示例](author-style-examples.md)。它是可选素材，不代表当前用户认可其中所有写法，且不能覆盖事实准确性、来源要求或当前指令。

需要沉淀新偏好时，先列出具体候选条目，沿用已有保存授权或取得用户同意，然后写入项目档案；不把新用户的经历、原话和偏好写回安装包。只做当次修改时不主动建立长期档案。

项目档案可按用语习惯、已确认偏好、避免的表达、标志性表达和平台差异组织；只有实际信息才新增条目，并记下来源日期。冲突时询问或保留不同适用条件。
