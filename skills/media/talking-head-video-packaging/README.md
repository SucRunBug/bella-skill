# 口播视频剪辑与包装

本目录属于 [bella-skill](https://github.com/SucRunBug/bella-skill) 合集。安装完整合集：

```bash
npx -y skills add SucRunBug/bella-skill -g --all
```

也可用 `--skill talking-head-video-packaging` 代替 `--all` 只装本项。安装后可直接调用 `$talking-head-video-packaging`。原仓库独立安装说明保留在下方。
