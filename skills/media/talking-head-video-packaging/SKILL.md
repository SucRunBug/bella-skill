# 口播视频包装

## 使用场景

适用于单人口播视频的完整包装，博主/内容创作者风格，支持 16:9 横版（1920×1080）与 9:16 竖版（1080×1920）。输入可以是原始口播视频（走完整流程），也可以是已完成 A-roll 粗剪的时间线（跳过精剪，直接从抠像/包装开始）。

典型触发词：「帮我做口播包装」「口播剪完了，加字幕/背景/B-roll/进度条」「按照我的口播模板包装一下」

## 运行环境与执行边界

本 skill 需要可用的 ChatCut Desktop 和相应剪辑工具。先检查是否能读取项目、时间线并进行所需编辑；可选的 `talking-head-guide` 等配套技能不随本合集捆绑，存在时再读取其流程。缺少某项能力时说明具体缺项，可交付剪辑方案与素材清单，不声称已编辑或导出视频。模板、米白背景和章节进度条不随本包提供，先检查用户项目；没有时按用户需求制作或省略，不能声称已从素材库取得。

已明确的画幅、抠像、背景和 BGM 选择直接沿用，只补问缺失且影响执行的项。只做字幕、配图等局部包装时，不强制执行整套流程。

原始视频的顺序：复制时间线 → 在副本上对原始整条视频抠像（仅当需要）→ 精剪并验证效果继承 → 包装 → 验证与导出。已粗剪输入直接在副本上处理现有片段。

## 0. 输入澄清

拿到视频后复用已有设置，一次补问以下缺失的关键选择：

1. 画幅：16:9 横版 / 9:16 竖版？
2. 是否需要抠图换背景：要 / 不要（保留原背景）？
3. 若需要抠图，背景图是否已提供：已提供（用用户提供的背景图）/ 未提供（用默认米白背景）？
4. 是否需要背景音乐：要（生成 1 首候选并确认）/ 不要（跳过，A1 留空）？

用户明确说由你决定时使用：9:16 竖版 + 抠图 + 米白背景 + 无 BGM。

## 需要的输入

- 原始口播视频，或已完成 A-roll 粗剪的时间线
- （可选）用户提供的背景图；未提供时用默认米白背景
- 米白背景图（默认，项目素材库中）
- 背景底图模版（用于了解布局：素材区、人物区、字幕区位置）
- B-roll 配图（按章节命名，如 skills1-xxx、01-湖景插画 等）
- 已沉淀的章节进度条 MG（从项目素材库调用，支持章节帧数参数）
- 章节起始帧列表（从转录/时间线中读取）

## 画面布局

### 9:16 竖版（1080×1920）

```
┌─────────────────────┐  ← 顶部：章节进度条
│  章节进度条 (top:0)  │
├─────────────────────┤  ← B-roll 区：顶部 1/4（height≈480, top:0）
│   B-roll 配图区      │     4:3 横版图，width:1080，按比例显示
├─────────────────────┤
│                     │  ← 人物区：下 3/4（top:480, height:1440）
│   人物（已抠像）     │     AI Portrait Cutout 去除原背景
│                     │     叠在背景图上
├─────────────────────┤  ← 字幕区：底部（参考底图模版位置）
│       字幕           │
└─────────────────────┘
```

### 16:9 横版（1920×1080，同比例映射）

- B-roll 区：顶部 1/4（height≈270, top:0），图按画布宽度适配。
- 人物区：下方 3/4（top:270, height:810）。
- 字幕区：底部安全区（参考底图模版位置）。
- 各元素尺寸按竖版同比例换算（示意参数，可按用户模板微调）。

## 工作流步骤

### 1. 输入澄清

执行「0. 输入澄清」，确认画幅、抠图、背景、BGM 后再开始。

### 2. 备份与 A-roll 精剪准备（输入为原始视频时）

- 先复制时间线，命名加「包装版」后缀；后续编辑都在副本上执行。
- 可用时读取 talking-head-guide 的 A-roll 流程：转写 → clean_script 机械清理 → 语义精剪 → apply_script。需要抠像时，先准备剪辑方案，待第 3 步整条抠像完成后再实际应用分段。
- 目标：去口癖/停顿/重录，保留完整语义单元与自然节奏。

### 3. 人物抠像（先全局、后分段）

**顺序：先对整条原始视频抠像，再精剪分段，子段继承抠像结果。**

1. 对原始整条视频 clip 添加 1 次 AI Portrait Cutout，等待处理完成（保持 ChatCut 桌面前台；查询分批，每次 ≤20 个 effect ID）。
2. 抠像完成后进行 A-roll 精剪分段。
3. 验证继承：抽帧确认所有子段背景透明；若有子段未继承 → 降级：仅对缺失段补挂效果，每批 ≤10 个。

输入已是粗剪时间线时：对每段挂 AI Portrait Cutout，分批挂载（每批 ≤10 个，完成后再挂下一批），全程保持 ChatCut 前台。

**卡住处理 SOP**：效果处理超过约 20 分钟无进展时——① 分批查询状态定位（每次 ≤20 ID）② 确认 ChatCut 桌面在前台（macOS App Nap 会挂起后台处理）③ 重启 ChatCut 桌面应用 ④ 仍无效则删除该批效果重新挂载。

### 4. 核对时间线副本

确认第 2 步已建立独立副本。已粗剪输入也应在任何编辑前复制，后续包装都在副本上操作。

### 5. 字幕

- 开启字幕，默认使用「青松手写体（Qingsong Shouxie Ti）」（ChatCut 字体库内置；如用户另有指定则按用户指定）。
- 字号：72px，字间距：1，白色字体，黑色阴影 85% 强度，无描边。
- 关键词红色高亮（`#FF3333`，fontWeight:700）：根据内容语义判断，典型如技术术语、产品名、核心卖点词。
- 字幕位置参考背景底图模版底部安全区。

### 6. 画面层搭建（轨道顺序从下到上）

| 轨道 | 内容 | 说明 |
|---|---|---|
| V1 背景 | 背景图（用户提供或默认米白） | 全程铺底，left:0 top:0，铺满画布 |
| V2 人声（anchor） | 口播视频 | 已含 AI 抠像；按画幅布局放置（竖版 height:1440 top:480） |
| V3 B-roll | 各章节配图 | 按画幅布局，与人物同时可见、不遮挡人物 |
| V4 MG标题 | 章节标题 MG | 每章节开场，时长2秒，极简细线风格 |
| V5 章节进度条 | 进度条 MG | 全程，调用已沉淀进度条 Skill |
| A1 背景音乐（follower） | BGM | 仅当输入澄清选择要 BGM；V2 设 anchor，A1 设 follower 自动闪避 |

### 7. B-roll 配图

- 根据语义在各章节关键时刻放置配图，每处约 3–4 秒。
- 尺寸位置按画幅布局：竖版 width:763，top:250，left:158（与底图模版素材区对齐）；横版同比例换算。
- 与人物同时可见，不遮挡人物。

### 8. 章节 MG 标题

- 每进入新章节时叠加标题，时长约 2 秒，放在 V4 轨道。
- 极简细线风格：深色文字、细横线装饰、淡入淡出。
- 首个 MG 经确认后，后续章节复用其视觉系统，保持一致。

### 9. 章节进度条

- 调用「进度条 Skills」制作或复用章节进度条。
- 确认章节帧属性与当前时间线章节起始帧一致。
- 进度条覆盖全程，放在最高视频轨道，并根据实际字幕和安全区确定位置。

### 10. 背景音乐（可选）

- 仅当输入澄清中用户选择要 BGM。
- 轻快、博主风、无人声、acoustic + electronic 混合，不分散注意力。
- 覆盖视频内容全长，超出部分截断，添加淡入淡出各 2 秒。
- 人声轨设为 anchor，音乐轨设为 follower，自动在人声下方闪避。

### 11. 验证

- 结构核对为主：preview_timeline timeline 视图检查轨道、条目数、图层位置（快）。
- 抽帧为辅：每章首尾各 1 帧 + 最后一帧，检查抠像、B-roll、章节标题、进度条、字幕。
- 不高频调用 viewer；全部合格后再导出。

### 12. 导出

- 按确认的画幅导出（竖版 1080×1920 / 横版 1920×1080）。
- 导出后抽帧核验，确认后交付文件。

## 关键规则

- 不删减内容：包装层只在 A-roll 之上叠加，不裁剪口播内容。
- 先抠像后精剪（输入为原始视频时）；子段未继承则降级补挂，每批 ≤10。
- 进度条帧数对齐：章节帧必须与实际章节起始帧一致。
- BGM 不超过视频结尾：音乐不能延长时间线。
- 抠像需要等待：AI 处理期间不要反复重试；保持 ChatCut 前台。
- 效果状态查询每次 ≤20 个 ID；卡住按 SOP 处理。
- B-roll 尺寸统一：所有配图沿用同一位置和尺寸系统。

## 完成检查

- [ ] 输入澄清已确认（画幅/抠图/背景/BGM）。
- [ ] 字幕青松手写体 72px、关键词高亮覆盖核心词。
- [ ] 抠像完成且所有段背景透明（无未继承段）。
- [ ] 进度条章节帧数与时间线一致。
- [ ] B-roll 所有图片位置一致，没有偏移。
- [ ] 章节 MG 标题视觉风格一致。
- [ ] 背景音乐（如有）在人声段落自动压低。
- [ ] 原始时间线未被修改，副本独立可编辑。
- [ ] 按确认画幅导出，成片抽帧核验通过。
