# 小红书Bot图文包

给一个主题，先确定配色、排版和IP；确认后再制作完整图文。适合省钱、平价好物、女生宿舍、零食求分享和避雷征集等Bot内容。

## 安装

```bash
npx -y skills add SucRunBug/bella-skill -g --skill xhs-bot-content-pack
```

## 使用

```text
使用 $xhs-bot-content-pack
主题：双十一女大学生宿舍平价好物征集
```

第一轮会交出视觉规范、封面问题、1个推荐标题和4个备选、正文、6–10个话题、首评、9款候选与来源、3页内文和选题逻辑。此时不生图。用户回复“确认，按这版生成”后，才制作默认的1张封面＋3张竖版内页，并交付带图Excel、文案、提示词、来源说明和压缩包。

可以补充预算、发布日期、品类、IP或参考图。比如：

```text
主题：没冰箱的女大都在囤什么零食？
条件：单份10元内、常温、小包装。
先给蓝白少女杂志风方案；猫咪用我提供的表情包。
```

先使用用户当前要求，历史图片只提供视觉参考。新主题不复用旧价格、旧热点或旧确认；不会自动发帖、下单或联系商家。已有方案、已批准视觉或局部修改会从当前阶段继续。

## 工具与资料

需要宿主提供联网检索、图片生成和电子表格能力；Python 3.10+用于离线校验和打包。Skill本身不会自动安装或开通模型。价格按实际购买整份标注，运费、会员和凑单条件另写；未取得可靠销量依据时不称Top榜。

规则入口：[SKILL.md](SKILL.md)。三张历史视觉图在`assets/style/`，图中的商品、报价和角色不代表本次任务已确定。完整包只收入清单中声明的文件，不扫描整个项目目录。
