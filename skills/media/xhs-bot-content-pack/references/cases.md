# 历史案例的可复用部分

## 厉娜鸭舌

创意为“当大学生说：鸭舌吃不起，厉娜”。预算痛点＋娱乐梗＋平价鸭货求分享，后续9款清单每页3款。封面参考 `assets/style/cover-duck.png`，该图保留了正确猫咪身份，并移除了“月薪喵”姓名气泡和“经验征集｜食物为示意图”。

可复用的是大问题、标签、角色、交错排版和“店名＋分量＋实付价”回答方式。不能复用旧报价，不能称鸭舌梗永远是最新热点，不能把候选清单叫已验证销量榜。

## 女大零食征集

标题“10元也能吃爽！女大零食求分享”；封面“没冰箱的女大／都在囤什么／零食？”。条件是单份10元内、常温、小份，内页分课间、宿舍追剧、晚自习前后。

封面参考 `assets/style/cover-snacks.png`，内页参考 `assets/style/interior-three-products.png`。一款的内容：商品图＋名称＋参考价/克重＋口味/渠道＋具体理由＋提醒。互动“名称＋口味＋克重＋购买渠道”，也收“吃两口就腻”的反例。

后续默认先提交视觉规范供确认。这比历史流程多了一道用户明确要求的步骤，不能因历史素材已存在就跳过。
