# 确认后使用的生图模板

本文件可在方案阶段用于准备文字，但调用生图必须等用户确认。不要因为模板完整就先画样张。

## 参考图

先看本地输入图，按当前工具能力使用路径或近期图像引用，不混用互斥参数。不超过工具当前参考数量上限。单页通常1张风格参考＋3张商品图；封面可用历史封面同时指明配色与IP身份。不要为了凑参考数量重复传图。

## 封面提示词骨架

用已批准的视觉规范制作3:4小红书Bot封面。风格参考仅保留配色、字体、层级和标签；IP参考仅保留角色身份；旧参考的商品、标题、日期、价格不进入新图。

顶部：本次账号标签与可选日期。
中间：本次封面问题，明确2–3行换行与重点词，粗大、手机缩略图可读。
下部：已批准IP姿态＋与主题相关元素，位置不挡文字。
底部：参与邀请＋简单回答格式。

逐字列出本次文字，列出主背景、阅读区、标题、正文、点缀HEX，指定安全边距。角色不打印名字，不增加未批准装饰。无二维码、无购物按钮、无新承诺。完整精致封面，不是设计说明。

## 三款内页提示词骨架

制作同系列第N/P张3:4内页，顶部账号标签、分组标题与页码。3横排交错：文字左/图右、图左/文字右、文字左/图右。保持已批准色彩、字体和信息层级。

分别说明每张商品图的品牌、口味、规格、需提取哪一件、应移除哪个旧背景。图片有两条而价格对应一条时，只提取一条。不发明品牌字样、包装、净重、配料或食物外观。

每款逐字给：名称、参考价/完整规格、口味与渠道、“选它”“提醒”。底部一句互动与必要短说明。商品照片清楚、不过度放大、不压字，正文手机可读。

## 核对与保存

1. 先检查封面，再完成一页作为系列锚点，随后其余页。
2. 对照最终数据表，逐条读品牌、口味、价格、克重、数量、日期、页码。
3. 看商品是不是正确口味/小份包装，防止用大袋图配小袋价；AI补写的包装微字也要看。
4. 错误优先局部修正并保留其他元素，再目检；未解决就明确缺口，不称完整交付。
5. 最终图复制进任务工作区，保留原始输出和最终提示词。不要用Python/HTML替代用户要求的图片生成，除非用户明确选择该路线。
